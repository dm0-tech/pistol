## Statement

In the tangent ∞-topos T𝐇 each fibre Sp(𝐇/X) is stable, hence pointed,
so A1 holds there. The base 𝐇 is a nondegenerate topos in which A1 fails
(Prop 0.5). Conjecture: logic (the bit ⊤ ≠ ⊥) lives in the base, and
possibility (𝕊-modules) lives in the fibres. Jaynes/Cox is a decategorifying
passage from fibre to base (π₀ ⊗ ℝ; Ω^∞ alone keeps too much). This is the
shape OP-8 asks about.
